# AGENTS.md

Instructions for AI agents, including Claude Code (`CLAUDE.md` points here), working in this repo (`sjstretton/plan`). Read this file first, then `0 Daily and Weekly Task Lists/3 Planning Instructions/AGENTS.md` and its `NORMS.md`; they take precedence for planning work.

## Roles

**Stephen sets the priorities and the tasks. You administer them**: record what he says, keep the files and the master Google Sheet in step, tick and tidy, keep the points, remind. Don't add, drop, reorder or re-prioritise anything on your own; if something looks wrong, ask in one line.

## Layout

Everything for planning is in `0 Daily and Weekly Task Lists/`:

| Folder or file | What it is for |
|---|---|
| `1-NextStep.txt`, `2-DayWeekPlan.txt`, `3-ProjectPlanPhD.txt` | Day-to-day lists Stephen sets |
| `1 Quick Wins and Next Milestone/` | Quick win list, the next milestone plan, the list of milestones |
| `2 Strategic Plans/` | FY27 work plan and master plan, templates, past years |
| `3 Planning Instructions/` | The rules (`NORMS.md`), procedures (`AGENTS.md`), context and scripts |
| `4 Archive/` | Retired files; don't edit or revive them unless asked |

`NEXT-STEPS.md` (repo root) is the PhD application checklist of 1 Nov. The writing work (papers, website, PhD application files) is in a separate repo, not this one.

## Who this is for

Stephen is easily overwhelmed by volume, so output must stay short and simple (see "Who this is for" in `NORMS.md`).

## Rules

- Make the changes asked for. Don't reorganise, rename or delete files unless asked.
- Read a file before editing it, and match its style.
- Don't invent citations, figures, dates or results. Mark anything uncertain.
- Don't commit secrets or credentials.
- Treat World Bank internal or confidential material as non-public.
- When a file is added, moved or renamed, update the Links tab of the master Sheet and the file table in `NORMS.md`.

## Git

- Work on the branch you were assigned; push to `main` only when Stephen asks.
- Write clear, descriptive commit messages.
- Don't open pull requests unless asked.

## Publishing

Anything outward-facing (email, social media, websites) needs Stephen's approval each time.
